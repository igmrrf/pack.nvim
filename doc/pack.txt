INTRODUCTION                                                 *pack-introduction*

pack.nvim is a Neovim plugin manager that leverages Neovim's native |vim.pack|
API to handle git cloning, lockfile management, and updating. It layers a
lazy-loading system, configuration management, and a floating UI dashboard on
top of the native features.

Features:
- Native Backend: all plugins under vim.pack's directory. Every plugin
  packadd-ed explicitly.
- Native Git, Async Probes: Clone/checkout/update/pinning by native vim.pack.
  Concurrency-limited async git probes for dashboard.
- Interactive UI Dashboard: floating window with real-time statuses, log
  streaming, pending-commit previews.
- Reproducible installs: Version pinning (branch/tag/commit/semver), native
  lockfile, :Pack restore.
- Persistent Disable State: via nvim-pack-extra.json.
- Performance Caching: ftdetect cache pre-compiled at startup.
- Lazy Loading: cmd, event (with patterns), ft, keys triggers.
- Modular Configuration: { import = "plugins" } for split specs.
- Fine-Grained Loading Control: enabled, cond, priority.
- Help Tags: auto-generated for managed plugins.
- Health Check: :checkhealth pack.

REQUIREMENTS                                                 *pack-requirements*

- Neovim 0.12+ (which includes |vim.pack|)
- `git` must be available on your PATH.

SETUP                                                              *pack-setup*

pack.nvim leverages Neovim 0.12's native |vim.pack| for bootstrapping.
Add this snippet to the top of your `init.lua`:

>lua
    -- Enable Neovim's built-in bytecode cache
    vim.loader.enable()

    vim.g.mapleader = " "
    vim.g.maplocalleader = " "

    -- Bootstrap pack.nvim using Neovim's native vim.pack
    vim.pack.add({
      { src = "https://github.com/igmrrf/pack.nvim", branch = "main" },
    })
    vim.cmd.packadd("pack.nvim")

    -- Initialize pack.nvim with options and plugin specs
    require("pack").setup({
      performance = {
        vim_loader = true,
      },
      ui = { border = "rounded" },
      plugins = {
        { "igmrrf/pack.nvim" },
        { "nvim-lua/plenary.nvim" },
        { "nvim-telescope/telescope.nvim", lazy = true, cmd = "Telescope" },
        { import = "plugins" },
      },
    })
<

After `setup()`, pack.nvim replaces the global `vim.pack.add`/`vim.pack.update`/
`vim.pack.del` with lazy-aware wrappers, so you can keep calling
`vim.pack.add({ ... })` and it flows through pack.nvim's loader.

PLUGIN SPECIFICATION                                         *pack-specification*

Plugins are defined using a table specification. The following fields are
supported for each plugin spec:

  [1] / src      (string) The plugin repository (e.g. "user/repo"), a full Git
                 URL, or a local path.
  as / name      (string) Custom name/alias for the plugin.
  dir            (string) Local development path for the plugin.
  lazy           (boolean) Defer loading of the plugin.
  priority       (number) Load order for eager plugins (higher loads first,
                 default is 50).
  enabled        (boolean|function) Whether the plugin is enabled. Can be a
                 function returning a boolean.
  cond           (boolean|function) Condition to load the plugin. Can be a
                 function taking the plugin spec and returning a boolean.
  main           (string) Override target module name for setup.
  cmd            (string|table) Lazy-load command triggers.
  ft             (string|table) Filetype triggers.
  event          (string|table) Autocmd event triggers.
  pattern        (string|table) Pattern filter for event triggers.
  keys           (string|table) Keymap lazy-load triggers.
  module         (string) Custom module name for require() tracking.
  dependencies   (table) Dependent plugin specs.
  init           (function) Callback executed before plugin load.
  opts           (table) Options table passed to `require(main).setup(opts)`.
  config         (function) Custom callback executed after plugin load.
  build          (string|function) Shell command or Lua function executed
                 post-install/update.
  branch         (string) Git branch to pin.
  tag            (string) Git tag to pin.
  commit         (string) Git commit hash to pin.
  version        (string) Semver version to pin.
  category       (string) Category metadata for dashboard filtering.
  tags           (table) Custom tags for dashboard filtering.

CONFIGURATION                                                *pack-configuration*

`pack.setup(opts)` accepts an `opts` table for configuration:

Options:
    `ui`             Table of UI configuration.
      `border`       String or Table. Window border style (e.g. "rounded").
      `filter`       String or Function. Filter input mode ("default",
                     "input", or callback).
      `auto_open`    Boolean. Auto-open when uninstalled plugins exist
                     (default true).
      `silent`       Boolean. Silence native vim.pack messages
                     (defaults to auto_open).
      `icons`        Table. Custom icons for the dashboard.
                     (e.g. `{ loaded = "✓", not_loaded = "✗", error = "!",
                     sync = "…" }`)

    `performance`    Table of performance configuration.
      `vim_loader`   Boolean. Fallback to ensure `vim.loader.enable()` is
                     called for performance caching.

==============================================================================
COMMANDS                                                         *pack-commands*

    :Pack             Open the pack.nvim dashboard.
    :Pack sync        Update all plugins and build them.
    :Pack update [name] Update specified plugin or all plugins.
    :Pack clean       Remove plugin directories no longer in configuration.
    :Pack restore     Roll every plugin back to the native vim.pack lockfile.
    :Pack repair      Align lockfile revisions to installed HEAD commits.
    :Pack build [name] Re-run build hook for a plugin (or all plugins).
    :Pack load <name> Load a lazy plugin immediately.
    :Pack delete <name> Delete plugin via native vim.pack.
    :Pack profile     Show startup profile load time chart.
    :Pack diff        Show pending updates diff for outdated plugins.
    :Pack picker      Open plugin picker (snacks.picker / vim.ui.select).

DASHBOARD KEYMAPS                                                 *pack-keymaps*

In the `:Pack` dashboard, you can use the following default mappings:

    `?`        - Show help popup
    `q`        - Close dashboard
    `<CR>`     - Toggle plugin details inline
    `K`        - Show full plugin details (commit info)
    `<Tab>`    - Cycle through tabs (Plugins -> Updates -> Disabled)
    `<S-Tab>`  - Cycle through tabs backward
    `1`/`2`/`3` - Jump directly to tab 1, 2, or 3
    `<Space>`  - Toggle selection on cursor plugin
    `v`        - Toggle selection UI mode / clear selection
    `S`        - Sync all plugins
    `s`        - Sync plugin under cursor
    `C`        - Clean unmanaged plugin directories
    `d`        - Delete plugin under cursor from disk
    `D`        - Delete all disabled plugins from disk
    `x`        - Toggle disable/enable on the cursor plugin
    `c`        - Check for outdated plugins
    `u`        - Update cursor or selected plugin
    `U`        - Update all outdated plugins
    `l`        - View logs for plugin under cursor
    `p`        - View startup load time profile
    `f`        - Filter plugins by name, cat:category, tag:tag

Each tab also displays a contextual quick help bar at the bottom.

LUA API                                                                *pack-api*

require("pack").setup(opts)
    Initialize pack.nvim with the given configuration options.

require("pack").add(specs)
    Dynamically add new plugin specs after setup.

require("pack").map_keys(keys)
    Helper to manually register lazy keymaps.

require("pack.state").set_disabled(name, disabled)
    Programmatically toggle the disabled state of a plugin by name.

require("pack").status()
    Return `{ total = <num>, loaded = <num>, disabled = <num> }`.

require("pack").stats()
    Return formatted status string (e.g. "📦 12/45 loaded").

require("pack").picker()
    Open interactive plugin picker (snacks.picker or vim.ui.select fallback).

LUALINE EXTENSION                                                *pack-lualine*

KNOWN LIMITATIONS                                            *pack-limitations*

Mixing native |vim.pack| calls with pack.nvim's declarative spec has two
sharp edges:

- A plugin installed by a raw `vim.pack.add()` call BEFORE
  `require('pack').setup()` that is ALSO declared in `setup()` with a
  `config`/`opts` will NOT have its pack.nvim `config` run, because native
  `vim.pack` already activated it and early-returns for already-active
  plugins. Declare such plugins only through pack.nvim, or avoid pre-setup
  raw adds for plugins that need `config`.
- When mixing imperative `vim.pack.add` calls inside `{ import = ... }`
  files with declarative specs, eager-load `priority` ordering is only
  guaranteed among declarative plugins; imperative-import plugins load in
  import order during `setup()`, not in the global priority sort.
- If the same plugin is registered both by an imperative `vim.pack.add`
  during an import and by a declarative spec, the first registration wins
  and the later spec's fields (lazy/config/keys/opts) are silently ignored;
  declare each plugin once, in one style.
