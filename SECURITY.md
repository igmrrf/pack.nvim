# Security Policy

## Supported Versions

Only the latest release and current `main` branch of `pack.nvim` receive security updates.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within `pack.nvim`, please do **not** open a public issue.

Instead, please report the vulnerability privately:
- Email the maintainer directly at `francis.igbiriki@gmail.com` with full details of the issue, steps to reproduce, and potential impact.
- Alternatively, submit a [Private Security Advisory](https://github.com/igmrrf/pack.nvim/security/advisories/new) on GitHub.

We will acknowledge receipt of your vulnerability report within 48 hours and provide a timeline for investigation and resolution.
